# 第三课参考复盘：怎样判断模型是不是当前瓶颈

交付实验：20 条随机训练轨迹、每阶段 1,000 次更新、8 条追加轨迹、8 个开发评测初始条件。模型、规划器与数据控制参数见 manifest。所有控制组每 3 步重规划一次。

## 1. 学习对象已经变了

网络学习 `(当前观测, 动作) → 下一观测增量`。CEM 根据已知成本函数搜索动作序列；MPC 执行第一段，并根据模拟器新的观测重算。没有动作策略网络或 SAC critic。

新训练标签来自真实 `env.step`。模型推演出的状态只用于搜索，不能被混作真实物理标签。

## 2. 第一个闭环成功，但这不代表模型毫无误差

| 控制方案 | 平均回报 |
|---|---:|
| 随机动作 | −1203.033 |
| 已知方程 + MPC | −139.158 |
| 初始神经动力学 + MPC | −139.159 |
| 初始数据多训练 | −139.307 |
| 补等量随机数据 | −139.292 |
| 补规划器访问数据 | −138.964 |

同样的规划预算下，初始模型的控制结果已接近已知方程参考。但多步误差图仍显示递推误差随时域增长。这两点可以同时成立：MPC 会在执行后用新观测重规划，且控制表现取决于任务相关区域的误差。

这提示我们下一步应检查评测任务是否足够区分模型、搜索预算是否限制了表现，或模型误差是否集中在不影响当前决策的区域。它还不能证明模型精度在其他任务里不重要。

## 3. 补规划器数据有巨大提升吗？没有

| 配对比较：planner_data 减参考 | 平均回报差 | episode bootstrap 95% 区间 |
|---|---:|---:|
| 相对初始模型 | +0.195 | [−0.009, +0.407] |
| 相对多训练 | +0.343 | [+0.123, +0.628] |
| 相对补随机数据 | +0.328 | [+0.060, +0.614] |

相对初始模型的区间跨 0；相对另两个追加训练对照的变化虽在这批配对 episodes 中可见，但绝对幅度非常小。不能把它写成重大突破，尤其这里只有一个训练 seed。

同初始状态的配对比较可以抵消一部分任务难度差异，所以它的区间可能比各组回报区间窄得多。这是配对实验的价值，不代表已经包含训练随机性。

## 4. 离线排序和闭环排序并不相同

| 模型 | 25 步角度 RMSE（rad） | 平均回报 |
|---|---:|---:|
| 初始模型 | 0.0905 | −139.159 |
| 多训练 | 0.0673 | −139.307 |
| 补随机数据 | 0.0894 | −139.292 |
| 补规划器数据 | 0.0912 | −138.964 |

多训练的模型在这项离线误差上最好，闭环回报却没有最好。因为模型误差是在随机验证轨迹上测的，而规划器访问的状态和动作分布不同；还有有限搜索与重规划反馈的作用。

这些变化都很小，不应从细微排序推出泛化很强的因果结论。更有价值的是建立“模型诊断”和“控制评测”两套指标，并知道何时应该扩大实验。

## 5. 第二个闭环完成在哪里？

模型先驱动 MPC 访问新状态，采集真实转移，再把它们加入训练；与相同标签数量、动作频率和初始 seed 的随机采集比较。三组都从同一 base 模型开始，追加相同更新预算，保留同一套归一化参数。

这把“模型 → 决策 → 新数据 → 模型改进”的回路闭上了，即使结果没有显著改善，实验本身仍给出了可解释的答案。
