# 08 · 第二课挑战题：Pendulum × SAC 六道对照实验

> 规则同三遍法：每题先在"预测"栏写下你的答案并 commit，再动手。
> 全部在 Mac CPU 上分钟级完成。改环境用 gymnasium Wrapper，模板见文末。

## C1 · 奖励手术：把力矩惩罚从 0.001 调到 0.1

- 改什么：自定义 reward，把 `0.001*u²` 换成 `0.1*u²`，SAC 10k 步。
- 预测：回报、保持向上时间比例、平均 |torque| 各怎么变？策略会变"懒"吗——懒到什么程度？
- 看什么：三个数字对照基线 + 看 GIF（动作是否变得柔和/是否干脆放弃摆上去）。
- 学什么：**权重就是目标之间的汇率**。调 100 倍等于宣布"能量比姿态贵 100 倍"，
  优化器会诚实地执行你的定价——哪怕定价是错的。

## C2 · 稀疏奖励：只给二元成功分

- 改什么：reward 改为 `1 if (|θ|<0.2 and |θ̇|<1) else 0`，SAC 10k 步。
- 预测：能学出来吗？为什么？
- 看什么：训练曲线是否全程平躺；replay buffer 里正奖励样本占比。
- 然后：加回一个微小的稠密项 `-0.01*θ²` 再跑一次，对比。
- 学什么：**稀疏奖励无偏但不可学**（随机探索几乎撞不到成功区，梯度=0），
  **稠密塑形可学但有偏**（把设计者的先验烧进了策略）。奖励设计的全部张力就在这两句。

## C3 · 预算曲线：Return = f(env_steps)

- 改什么：SAC 在 2k / 5k / 10k / 20k 步各训一次，每档 2 个 seed。
- 预测：曲线形状？10k 和 20k 之间还有多少提升？seed 间差异比档间差异大还是小？
- 看什么：带散点的 return-vs-steps 曲线（每档 2 点不连线，画出 spread）。
- 学什么：这是 RL 版的 Success=f(N)——**样本效率曲线**；顺便体会为什么
  "SAC 10k 不保证收敛"写在 README 里。评测遵守 NB03 协议。

## C4 · 公平对决：同墙钟时间的 SAC vs PPO

- 改什么：不比相同 env steps，改比相同训练时长（各 90 秒，用 time.time() 掐）。
- 预测：谁赢？和"同 10k 步"的结论一致吗？
- 看什么：各自实际消耗的 env steps、updates 数、最终 return。
- 学什么：**同步数 ≠ 同算力 ≠ 同墙钟**。off-policy(SAC) 每步贵但复用数据，
  on-policy(PPO) 每步便宜但用完即弃——比较协议决定谁"更好"，协议是你选的。

## C5 · 合同压力测试：力矩上限砍半

- 改什么：ActionWrapper 把动作裁剪到 [-1,1]（原来 [-2,2]），SAC 15k 步。
- 预测：还能摆上去吗？如果能，行为和原来有什么可见差别（提示：荡几次秋千）？
- 看什么：GIF 里蓄力摆动的次数；保持向上比例。
- 学什么：**最优行为是"任务合同的函数"**。同一个环境，改一行执行器约束，
  最优策略的形态整个改变——这就是为什么审计要盯 actuator/gear 这类"无聊常数"。

## C6 · 观测消融：删掉角速度

- 改什么：ObservationWrapper 只保留 [cosθ, sinθ]，SAC 10k 步。
- 预测：还能学吗？卡在什么水平？为什么？
- 看什么：return 对照基线；看 GIF 里是否出现"该刹车时不刹车"。
- 学什么：**马尔可夫性的现金价值**。没有速度，单帧观测分不清"荡过去"和"停着"，
  最优决策不存在——第一课"为什么 obs 里要有 velocity"这次用回报差价量化给你看。

## 通用 Wrapper 模板

```python
import gymnasium as gym
import numpy as np

class RewardSurgery(gym.Wrapper):          # C1 / C2
    def step(self, action):
        obs, _, terminated, truncated, info = self.env.step(action)
        theta = np.arctan2(obs[1], obs[0])          # 从 cos/sin 还原角度，天然在 [-pi,pi]
        theta_dot = obs[2]
        reward = -(theta**2 + 0.1*theta_dot**2 + 0.1*float(action[0])**2)   # 改这里
        return obs, reward, terminated, truncated, info

class HalfTorque(gym.ActionWrapper):        # C5
    def action(self, a):
        return np.clip(a, -1.0, 1.0)

class NoVelocity(gym.ObservationWrapper):   # C6
    def __init__(self, env):
        super().__init__(env)
        self.observation_space = gym.spaces.Box(-1.0, 1.0, (2,), np.float32)
    def observation(self, obs):
        return obs[:2].astype(np.float32)

# 用法：env = RewardSurgery(gym.make("Pendulum-v1"))，然后照常喂给 SAC
```
