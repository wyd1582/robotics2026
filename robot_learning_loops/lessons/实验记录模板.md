实验记录：一次完整闭环

日期 / 项目 / Git SHA / run目录：

1. 我试图解决的具体失败是什么？观察证据是什么？

2. 假设是什么？如果它错了，什么结果会推翻它？

3. 输入数据从哪里来？episode/task/scene划分是什么？是否含未来信息？

4. 模型学的是动作、价值还是动力学？动作表示/单位/频率是什么？

5. 唯一改变的变量是什么？数据量、标签成本、更新步数、算力哪些保持一致？

6. baseline是什么？为什么不是一个明显太弱的baseline？

7. 训练与验证曲线如何？模型保存/重载是否一致？

8. 闭环执行的成功次数/总次数、回报、误差、时延与失败视频是什么？

9. seed/episode区间支持什么结论？不能支持什么结论？是否已经看过测试集？

10. 失败主要来自数据/感知/策略/控制/环境模型/评测中的哪一层？如何区分？

11. 下一轮只做什么干预？预计需要多少数据/标签/时间？

12. 若要开源贡献，现有仓库是否已有这个功能？最小复现和回归测试是什么？

写作要求：结果没有提高也照实记录。把“代码跑通”“小实验有效”“论文复现”“真机验证”分别表述。
