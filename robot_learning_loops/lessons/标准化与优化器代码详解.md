# 输入标准化 × 优化器：从代码到实验结论

对应文件：`robot_learning_loops/notebooks/01_机械臂模仿学习.ipynb` 中的“实验四”。以下依据本地 notebook 与 `robot_learning_loops/loop01_imitation.py` 的实际定义。

## 这段实验在解决什么问题

训练同一种行为克隆网络，让它从 10 维观察预测专家的 2 维控制命令。比较两个因素的四种组合：输入观察是否标准化，以及使用 SGD(0.01) 还是 Adam(0.001)。每组训练 1000 次参数更新，返回验证集原始动作尺度的 MSE。

`standardize=False` **只关闭输入标准化**。四组实验的专家动作标签仍全部标准化，预测动作也仍需还原尺度。`std` 在推导式里是布尔开关，不是标准差数值。

## Actor 是什么

Actor 是产生动作的策略模型。这里是确定性神经网络，结构为 `10 → 128 → 128 → 2`，隐藏层使用 Tanh。它学的是“在这个观察下，专家会发出什么控制命令”。这属于监督学习式行为克隆；使用 Actor 这个名称不表示已经采用 Actor-Critic，也没有要求一定存在 Critic。

`Actor(...)` 创建模型；`model.parameters()` 返回要训练的权重和偏置。优化器改变这些参数。`x_mean/x_std/a_mean/a_std` 通过 `register_buffer` 保存：会跟随模型保存、加载和设备移动，但不作为梯度优化参数。

实际的数据流：

```text
原始观察 x（10 维）
  → 按训练集统计量转换输入
  → 神经网络
  → 标准化动作预测 z_hat（2 维）
  → 乘动作尺度并加动作均值
  → clamp 到 [-1, 1]
  → MuJoCo 的 2 维控制命令
```

`model.standardized(x)` 接收原始输入，在内部转换输入，返回标准化动作预测。`model(x)` 则返回还原尺度并裁剪后的动作，两个调用的输出尺度不同。

## 标准化的公式与具体实现

对训练集第 j 个观察特征，求均值和标准差：

$$
\mu_{x,j}=\frac{1}{N}\sum_{i=1}^N x_{ij},\qquad
s_{x,j}=\max\left(\sqrt{\frac{1}{N}\sum_{i=1}^N(x_{ij}-\mu_{x,j})^2},0.01\right).
$$

输入转换为：

$$z_{x,ij}=\frac{x_{ij}-\mu_{x,j}}{s_{x,j}}.$$

这里 NumPy `.std(0)` 默认使用分母 N（`ddof=0`）。代码是：

```python
x_mean = train["obs"].mean(axis=0)              # shape: (10,)
x_std = np.maximum(train["obs"].std(axis=0), .01)
x_scaled = (x - x_mean) / x_std                 # shape: (N, 10)
```

`axis=0` 表示跨样本计算，每列独立获得一个统计量。NumPy/PyTorch 会广播这 10 个数到每个样本。不是对一行的 10 个混合物理量算一个均值。

举例（仅示意，并非该训练集实测统计）：某个位置特征训练均值为 0.10 m、标准差为 0.02 m，那么 0.14 m 对应 `(0.14 - 0.10) / 0.02 = 2`，表示高于训练均值两个标准差。

0.01 是分母下限，避免近似常量特征造成除零或过度放大。它不是把数据最小值设成 0.01。由于这个下限存在，转换后的标准差不一定严格等于 1；验证数据也不必均值为 0、标准差为 1。标准化不保证高斯分布，不把数值限制到 [-1,1]，也不会消除异常值或特征相关性。

动作标签也按列转换：

```python
a_mean = train["expert_action"].mean(axis=0)    # shape: (2,)
a_std = np.maximum(train["expert_action"].std(axis=0), .01)
target = (y - a_mean) / a_std
```

网络预测标准化动作后，实际控制命令为：

$$\hat a=\operatorname{clip}(f_\theta(z_x)\odot s_a+\mu_a,-1,1).$$

`⊙` 表示逐元素乘法。动作标签的尺度标准化与执行器 gear 的物理转换是两件事；这里还原的仍是控制命令，不是绕过 gear 直接得到关节力矩。

关闭输入标准化时，代码传入 10 个 0 和 10 个 1：

```python
Actor(np.zeros_like(x_mean), np.ones_like(x_std), a_mean, a_std)
```

于是 `(x - 0) / 1 = x`。这是将变换设为恒等映射，不代表原始数据实际上均值 0、标准差 1。

## 为什么标准化

观察同时含三角函数、米制位置和角速度。神经网络首先计算类似 `w1*x1 + w2*x2 + ...` 的加权和。不同数值尺度会影响梯度、学习率的适用范围及 Tanh 是否进入梯度很小的饱和区。合适的缩放通常让优化更稳定，尤其便于 SGD 使用共享的基础学习率。

这和量化中用均值/波动率标准化不同因子的直觉相通：数值大不代表信息更多。但缩放本身不会创造新信息，标准化也不是所有模型、所有任务的必选项。

Adam 根据梯度历史为不同参数调整更新幅度，通常比普通 SGD 更能适应部分尺度差异，但不是输入标准化的替代品，也不会自动修正数据泄漏或饱和等所有问题。

只用训练集拟合均值与尺度，验证、测试、部署复用同一套统计量；在验证/测试集重新拟合会改变问题并引入泄漏风险。

动作标签标准化还有一个含义：未裁剪预测的标准化 MSE，相当于按动作维度的 `1 / a_std**2` 加权原始动作误差。所以训练 loss 与原始尺度验证 MSE 不能直接比较数值。本实验对四组使用同一套动作统计量，验证 MSE 的尺度一致。

## 将字典推导式展开

原代码：

```python
grid = {(std, name): train_variant(std, fac)
        for std in [True, False]
        for name, fac in {"sgd": lambda p: torch.optim.SGD(p, lr=1e-2),
                          "adam": lambda p: torch.optim.Adam(p, lr=1e-3)}.items()}
```

适合学习的等价写法：

```python
def make_sgd(parameters):
    return torch.optim.SGD(parameters, lr=0.01)

def make_adam(parameters):
    return torch.optim.Adam(parameters, lr=0.001)

optimizer_factories = {"sgd": make_sgd, "adam": make_adam}
grid = {}

for use_standardization in [True, False]:
    for optimizer_name, make_optimizer in optimizer_factories.items():
        validation_mse = train_variant(use_standardization, make_optimizer)
        grid[(use_standardization, optimizer_name)] = validation_mse
```

逐项理解：

- `{key: value for ...}`：Python 字典推导式，是创建字典的循环简写，不是数学方程。
- `for std in [True, False]`：先运行开启输入标准化的组，再运行关闭的组。
- `{"sgd": ..., "adam": ...}`：键是优化器名称，值是创建优化器的函数。
- `.items()`：依次取得 `(键, 值)` 对；`name, fac` 把每一对拆成两个变量。
- `lambda p: ...`：匿名函数。p 是调用者之后传进来的网络参数，不是概率。
- `fac`：factory 的缩写，这里指“用给定参数创建一个优化器”的函数。
- `1e-2` 是 0.01，`1e-3` 是 0.001，`lr` 是 learning rate。
- `train_variant(std, fac)`：新建并训练一个模型，返回一个浮点验证 MSE。
- `(std, name)`：元组键，例如 `(True, "adam")`。整个字典只有四条记录。
- 四组训练按循环顺序串行执行；创建 lambda 不会立即开始训练。

可单独读取：

```python
grid[(True, "adam")]
grid[(False, "sgd")]
```

优化器延迟到模型创建后再实例化，是因为每个新模型有自己的一套参数；Adam 等优化器还有自己的状态，不应让四个模型误用同一个优化器对象。

## train_variant 内部运行顺序

1. 根据布尔参数选择真实输入统计量，或用 0 和 1 禁用输入转换；两条分支都保留动作标准化。
2. 将训练观察、专家动作转换为 float32 张量。
3. `opt_factory(model.parameters())` 为这个模型创建独立优化器；`default_rng(SEED)` 创建批次抽样器。
4. 1000 次循环中，每次有放回抽取 256 条样本。1000 updates 不是 1000 epochs。
5. `model.standardized(x[idx])` 预测标准化动作；`(y[idx]-a_mean)/a_std` 生成相同尺度的标签。
6. 相减、平方、`.mean()`：对 256 个样本和每个样本的 2 个动作误差一起求平均。
7. `zero_grad` 清除旧梯度；`backward` 算当前梯度；`clip_grad_norm_(..., 5.)` 限制合并梯度的范数；`step` 更新权重。梯度裁剪不等于动作裁剪。
8. `inference_mode` 关闭评估所需之外的梯度跟踪；`model(val_obs)` 返回原始控制尺度并裁剪后的预测。
9. 与验证专家动作计算 MSE，`.item()` 取出 Python 浮点数，存入 grid。

## 公式记号与书写方式

$$\pi_\theta(o_t)\approx a_t^*$$

- π：policy，策略函数。
- θ：网络所有可训练权重和偏置。
- o_t：t 时刻的观察。
- a_t*：这里表示 t 时刻的专家动作标签，不表示已证明全局最优。
- ≈：训练目标是尽量接近专家动作。

在 Jupyter 的 Markdown 单元中，用 LaTeX 记号书写，例如行内 `$\pi_\theta(o_t)\approx a_t^*$`，独立公式使用 `$$...$$`，再按 Shift+Enter 渲染。Python Code 单元则要使用 Python 语法。

这里四个数都是验证动作 MSE，越小越接近专家标签。当前实验中两种配置都从标准化获益，Adam 配置更低。

但 `default_rng(SEED)` 只固定批次，没有在每次新建 Actor 之前重置 PyTorch 的初始化随机数。不同组可能具有不同初始权重。更稳妥的配对实验是在 `train_variant` 内、创建 Actor 前加 `torch.manual_seed(SEED)`，并用多个 seed 重复。SGD 与 Adam 的学习率不同，不能从这一次配置比较推出某种优化器普遍更好。

下一步还要把四个模型放到同一批独立仿真场景上，比较末端距离、稳定性、成功率及失败案例。当前函数只返回 MSE，没有返回模型；如果要做 rollout，需要把返回值扩展为 `(mse, model)` 并同步修改结果收集代码。低动作 MSE 不保证闭环控制成功。
