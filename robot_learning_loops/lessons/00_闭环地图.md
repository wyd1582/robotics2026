从量化研究到机器人：先把闭环画对

学习目标：能指出任何一个机器人项目的数据来源、被学习的函数、执行接口、评价指标与下一轮数据来源。

一个序列决策系统只有几个核心对象：

- 物理状态 s_t：世界真实处于什么状态，通常不能全部观察。
- 观测 o_t：相机、关节编码器等提供的信息，有噪声与延迟。
- 动作 a_t：力矩、位置目标或末端位姿变化。必须知道单位、坐标系、控制频率和执行方式。
- 转移 s_(t+1)=f(s_t,a_t,扰动)：动作改变世界，再改变未来观测。
- 目标 J：任务完成、时间、能耗、约束违反等需要明确权衡。

“预测”本身并不构成闭环。只有动作进入系统、产生新状态、反馈到下一次决策，才是闭环。

| 量化/DS 环节 | 机器人对应物 | 类比的边界 |
|---|---|---|
| raw data / point-in-time | 图像、状态、动作、采样与到达时间 | 动作还会主动改变之后的观测分布 |
| 信号/标签定义 | 专家动作、任务成功、奖励、下一状态 | 标签不只有一种；不同标签对应不同学习路径 |
| signal model | policy、value/Q 或 dynamics model | policy输出动作；dynamics预测下一状态，职责不同 |
| portfolio optimizer | 规划器、控制器、动作仲裁/约束层 | 它们可学习也可手写，并非所有系统都有同样层级 |
| backtesting toolbox | 固定环境/初始条件的 rollout evaluator | 静态日志不能回答未执行动作的真实后果；仿真是有误差的模型 |
| paper trading / live | 仿真闭环 / 真机运行 | 真机还涉及标定、时钟、执行器、接触、限位、人工介入 |
| 归因与再训练 | 失败分类、恢复演示、域随机化、模型修复 | 需要区分“数据变好”“多训练了”“评测变容易了” |

市场冲击/内生性意味着量化里也有动作影响未来的情况；机器人把这种耦合放在每一步显式处理。

不要把所有算法看成互斥赛道。可以用四个轴定位一个方法：

| 轴 | 选项举例 |
|---|---|
| 监督信号从哪里来 | 人/控制器示范；环境奖励；下一状态预测；预训练知识 |
| 学到什么 | 动作策略；价值函数；动力学/世界模型；视觉或语言表征 |
| 输入输出形式 | 低维状态/图像/语言；单步动作/动作块/技能目标 |
| 如何执行 | 直接执行；滚动规划；经低层控制器；带约束与人工监督 |

因此 VLA 常仍使用模仿学习，Diffusion Policy 是动作分布与动作序列的建模方式，MPC可使用手写或学习动力学，RL可用于微调已有策略。它们可以组合。

本练习册的复现阶梯：

1. BC + 纠正数据：先学“o -> a”，观察状态分布偏移。
2. SAC/PPO：改为根据奖励改善策略，理解探索、replay与训练预算。
3. Dynamics + MPC：学“o,a -> o_next”，让规划器选择动作。
4. ACT/Diffusion：把低维单步策略升级为视觉动作序列模型。
5. VLA：加入语言条件与预训练迁移，验证语义是否真的影响执行。

最短有效学习单位是一次有记录的因果尝试：一个失败假设 + 一个干预 + 公平对照 + 独立执行反馈。下载仓库、读完论文、loss下降都不是完成标准。

选择研究方向时，前三个项目每个安排一个完整半天到两天的动手周期；机器运行时长通常更短，时间花在解释结果和改代码。之后只选最让你愿意继续debug的一个问题推进到项目4/5，避免同时维护五条长期路线。

你最有优势的后续课题：数据选择/恢复数据效率、时序错误与部署延迟、跨场景失效归因、模型评测的统计可信度。先用这套练习证明你能训练和执行策略，再把数据科学深度加进去。

第一遍只需要懂：episode（一次完整尝试）、observation（可见输入）、action（执行命令）、policy（决策函数）、rollout（逐步执行的轨迹）、checkpoint（冻结参数）。其他概念在各项目用到时再学。
