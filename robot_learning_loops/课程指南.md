# 从三个完整闭环开始

这组课面向已经会 Python、统计建模或量化研究，希望建立机器人学习手感的人。每课都使用“提出问题 → 跑出证据 → 复盘 → 只改一个变量”的顺序。

| 顺序 | 你要解释的问题 | 学习对象 | 当前交付 |
|---|---|---|---|
| 01 | 模仿专家，为什么执行仍走偏？ | 观测到动作的策略 | 已执行 Notebook、HTML、数据、回放和讲评 |
| 02 | 没有动作标签，怎样从奖励学控制？ | actor、critic 与 replay | 已执行 Notebook、HTML、预算对照和讲评 |
| 03 | 先预测物理，再规划；新数据能否修复模型？ | 动力学模型 + CEM/MPC | 已执行 Notebook、HTML、完整重训对照和讲评 |
| 04 | 观测变成图像，动作变成序列后有什么变化？ | ACT / Diffusion Policy | 讲义与固定版本启动计划；训练尚未验证 |
| 05 | 语言、视觉、状态怎样共同产生动作？ | SmolVLA / LIBERO | 讲义与固定版本启动计划；训练尚未验证 |

## 第一轮：每课只交一页自己的复盘

- 第一课：说清专家标签、执行动作、训练误差与闭环成功的区别；解释三个追加训练对照。
- 第二课：画出一行 transition 的流向；解释动作缩放与时间截断；用独立评测比较训练预算。
- 第三课：说清学到的函数与动作搜索器；解释单步/多步误差；比较追加计算、随机数据与规划器数据。

Notebook 中的 `MY_PREDICTION` 在运行前写，`MY_REVIEW` 在看到结果后写。重新执行最后的复盘格，答案会保存到该次实验的 `review.md`。自己的回答先于参考讲评。

## 启动方式

在本目录运行：

```bash
uv sync --locked --group notebooks
uv run --locked --group notebooks jupyter lab
```

按顺序打开：

1. [01_机械臂模仿学习.ipynb](notebooks/01_机械臂模仿学习.ipynb)
2. [02_强化学习与经验回放.ipynb](notebooks/02_强化学习与经验回放.ipynb)
3. [03_世界模型与规划迭代.ipynb](notebooks/03_世界模型与规划迭代.ipynb)

如果只想读已有结果，下载同名 `.html` 用浏览器打开。所有动画来自实际模拟状态，已嵌入文件。

第一课的参考讲评为 [参考复盘.md](notebooks/参考复盘.md)，后两课分别为 [02_参考复盘.md](notebooks/02_参考复盘.md) 与 [03_参考复盘.md](notebooks/03_参考复盘.md)。

## 第二轮：练习独立研究

每次只选一个问题，冻结其余配置。运行前写明会支持或反驳假设的指标；运行后保留差结果。跨训练 seeds 验证，再考虑新的、未触碰的最终评测集。

不要将三个课程的默认分数直接排序：环境、动作频率、训练数据和规划预算未全部对齐。要比较 SAC 和 MPC，需要另设共同协议，包括初始状态、动作周期、交互预算和计算耗时。

## 与原有 NB00–NB08 的关系

仓库根目录的 `notebooks/` 是原有系列；本目录是三个具体任务的完整示范。可以先从一个完整示范建立框架，再回到原有系列练数据分析、评测统计和失效归因。两套目录的编号独立。

每次学习只开当前需要的 kernel。结束时关闭 kernel，并在启动 Jupyter 的终端按 Ctrl+C 结束服务，释放内存。

## 维护与批量复验

以下命令会重新执行后两课并替换其保存的输出，运行前先保存自己的笔记或另存副本：

```bash
uv run --locked --group notebooks python tools/execute_notebooks.py 02_强化学习与经验回放.ipynb 03_世界模型与规划迭代.ipynb
```

`tools/build_followup_notebooks.py` 是讲义源码生成器，会重建 Notebook 源文件并清除已有输出；日常学习不需要运行它。
